# Сайт-визитка ориентировщика

Статичный сайт: `index.html` + `style.css` + папка `images`. Никаких сборщиков, всё правится в обычном текстовом редакторе.

## Как редактировать

Откройте `index.html`. Всё, что можно менять, помечено комментарием `✏️`.

- **Имя, подпись, «Обо мне»** — просто замените текст.
- **Фото** — положите файл в папку `images` и впишите его имя в `src`. Аватар: `images/avatar.jpg`. Галерея: `photo1.jpg` … `photo4.jpg`. Пока файла нет, показывается заглушка.
- **Достижения** — один блок `<article class="award">` = одно достижение. Скопируйте блок и поменяйте год, название, результат.
- **Ссылки** — в разделе «Финиш» поменяйте `href` у кнопок. Лишние удалите, новые добавьте копированием.
- **Цвета** — в начале `style.css`, блок `:root`. Поменяли один цвет, и он поменялся везде.

Посмотреть результат: просто откройте `index.html` двойным кликом в браузере.

## Как выложить на GitHub Pages

1. На github.com создайте репозиторий. Если назвать его `ваш-логин.github.io`, сайт будет по адресу `https://ваш-логин.github.io`.
2. Загрузите в него все файлы (кнопка **Add file → Upload files**, папку `images` перетащите целиком) и нажмите **Commit changes**.
3. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт появится по адресу, который GitHub покажет на этой же странице.

Чтобы обновить сайт, правьте файл прямо на GitHub (иконка карандаша) или загружайте новые версии, и страница пересоберётся сама.

## Советы

- Фото лучше сжимать до 200–400 КБ, иначе сайт будет грузиться долго.
- Фото 4:3 в галерее смотрятся ровнее всего, но другие форматы тоже обрежутся аккуратно.
